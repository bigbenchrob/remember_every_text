# Implemented UI/UX Reviews

This folder stores completed and verified UI/UX review documents.

Keep the folder hierarchy parallel to the active review tree. For example:

```text
10-Messages-Sidebar/Conversations/
```

should move here as:

```text
99-IMPLEMENTED/10-Messages-Sidebar/Conversations/
```

Do not delete implemented reviews. They are design history and help explain
why the current interface behaves as it does.
