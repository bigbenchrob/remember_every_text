# UI Walk Registers

This folder stores cross-review registers for the WALK-UI process.

Registers are for items that span more than one review document or that should
remain visible after a single surface review is complete.

Examples include:

- implementation debt
- future design concepts
- deferred cleanup items
- decisions that should be revisited after a broader UI pass

Registers are not bug lists. They track agreed, likely, or intentionally
deferred UI decisions so they are not lost while the walk stays focused on one
surface at a time.
