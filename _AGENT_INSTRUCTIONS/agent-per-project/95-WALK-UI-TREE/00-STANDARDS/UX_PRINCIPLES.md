# UX Principles

## One Conversation

There is only one Conversation.

A Conversation is a canonical graph entity. It may appear through many lenses:
Search results, the Conversation browser, Contact pages, Favourites, Discovery,
and right-side conversation excerpts. These are manifestations of the same
underlying object, not separate local copies.

Actions performed on a Conversation in one lens should affect that same
Conversation everywhere. For example, toggling Favourite on a Conversation Card
in the right sidebar should update the same Conversation in the Conversations
view.
