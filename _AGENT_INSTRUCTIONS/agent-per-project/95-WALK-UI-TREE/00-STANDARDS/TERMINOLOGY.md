# Terminology

## Conversation

Use `Conversation` for the canonical graph entity that represents a message
thread or chat-level communication structure.

Avoid treating appearances of a Conversation in different UI locations as
separate things. Say that a Conversation appears in a lens, excerpt, result, or
card, but preserve the meaning that it is the same underlying Conversation.

## Lens

A lens is a way of viewing or organizing the same underlying entities. Search,
Favourites, Contact pages, Conversation browser views, and right-side excerpts
may all show Conversations through different lenses.
