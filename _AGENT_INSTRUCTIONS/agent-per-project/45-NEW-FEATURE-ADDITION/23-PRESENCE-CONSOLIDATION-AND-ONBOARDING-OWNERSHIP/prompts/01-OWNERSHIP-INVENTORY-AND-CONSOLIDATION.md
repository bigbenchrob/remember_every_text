# Ownership Inventory And Consolidation Prompt

This package begins the transition from the completed Presence experiments to
a permanent architecture.

Inventory the current repository and test this provisional ownership model:

```text
Presence
    generic workflow machinery

Onboarding
    onboarding workflow meaning

specialist features and essentials
    concrete expertise requested by onboarding

development harness
    repeatability, substitution, diagrams, trace, and visualization
```

Classify relevant files, establish a permanent Onboarding home, and make only
mechanically safe ownership moves. Preserve all behavior and persistence.

Do not implement generic `TestStep`, Agent registries, persisted Agent IDs,
new routing, schema changes, production onboarding integration, or additional
blockers. Record ambiguous ownership rather than resolving it implicitly.
