⚠️ Key Things to Avoid

These are subtle but important:

Avoid hedging language

* “should”
* “appears to”
* “likely”

→ makes users doubt the result

⸻

Avoid internal terminology high up

* “reconciled”
* “resolver”
* “pipeline”

→ fine lower down, not in the headline

⸻

Avoid implying global truth

Never say:

“All your messages are here”

Always say:

“on this Mac”

You’re already doing this correctly — keep it tight.
