How the trainer schedules reviews

Each card starts as a new lesson. After you answer, choose how it felt. The scheduler uses short intervals for weak answers and longer intervals for confident ones.

  • Again: repeat soon, usually tomorrow.
  • Hard: keep the interval short.
  • Good: move from one day to about one week, then longer.
  • Easy: extend faster when the pattern is automatic.

The deck is biased toward architecture docs: headings, ADRs, diagrams, tables, links, code fences, callouts, and review checklists.
