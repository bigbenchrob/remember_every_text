# identity

## Prompt

```text
Pause feature work and audit contact/participant identity display resolution.

Goal:
Move the app toward one graph-backed identity/display-name system.

Problem:
The message evidence spine is now largely centralized, but contact/participant naming still appears partially legacy-shaped. Some surfaces still show raw handles or phone numbers where a known contact/user-assigned display name should win.

Core rule:
User override name wins everywhere.
Then known contact display identity.
Then best available contact/address-book name.
Then raw handle as fallback only.

Audit:
1. Find every path that renders:
   - contact names
   - conversation participant labels
   - sender labels
   - handle labels
   - conversation titles
   - unfamiliar-source labels

2. For each, report:
   - data source: graph, overlay, AddressBook, legacy working.db, raw handle
   - whether user override is considered
   - whether raw handle can incorrectly win over known identity
   - which widget/view uses it

3. Identify the current canonical candidate for display-name resolution, if one exists.

4. Propose one canonical display identity resolver/read model for:
   - contact display name
   - participant display label
   - conversation title/participant summary
   - sender line display label
   - handle fallback display

5. Do not change schema yet unless absolutely necessary.

6. Do not modify message evidence rendering.

7. Do not create source-specific naming fixes in individual widgets.

Deliverable:
Create a short CONTACT_IDENTITY_DISPLAY_AUDIT.md with:
- current state
- problematic paths
- proposed resolver contract
- precedence rules
- migration sequence
- tests needed

Recommended precedence:
1. User-assigned app display name / override
2. App-known contact identity
3. AddressBook / imported contact name
4. stable conversation participant label
5. raw phone/email/handle fallback

Important:
Handles should remain visible as metadata or explicit handle-scope controls, but should not be the primary label for a known person unless no better identity exists.
```
