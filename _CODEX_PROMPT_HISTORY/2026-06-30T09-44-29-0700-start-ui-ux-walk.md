# Start UI/UX walk

## Prompt

```text
We are beginning a new phase of the MessageLens project.

The major architectural cleanup is largely complete. The priority now shifts from improving architecture to systematically improving the user experience.

Please familiarize yourself with the contents of:

95-WALK-UI-UX/

In particular:

- README.md
- UI_REVIEW_PROCESS.md
- REVIEW_TEMPLATE.md
- ACTION_PLAN_TEMPLATE.md

These documents define the review process that will guide this phase.

Going forward, the normal workflow will be:

1. I choose a UI surface to review.
2. Together we discuss and complete the corresponding review document.
3. When the review is mature, you produce an implementation plan using ACTION_PLAN_TEMPLATE.md.
4. You implement only the agreed changes.
5. We verify the result before moving on.

Important principles for this phase:

• Stay tightly scoped to the review document.
• Resist making unrelated "drive-by" improvements.
• Preserve the existing architecture unless a review explicitly requires otherwise.
• Prefer improving clarity, discoverability, consistency and workflow over adding new features.
• Favor small, polished iterations over broad rewrites.
• If you identify additional UX issues outside the current review, record them as suggestions for future review documents rather than expanding the implementation scope.

The objective is not to redesign MessageLens from scratch.

The objective is to systematically remove friction until every user-facing surface feels obvious, consistent and polished.

Please read the documents and briefly summarize your understanding of this review process before we begin the first UI walkthrough.
```
